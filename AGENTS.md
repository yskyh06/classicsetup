# ClassicSetup Codex instructions

After every implementation task, update `.ai/handoff.md`.
Keep the handoff concise and include only these sections:

- Current milestone
- Changed files
- Implementation result
- Build/test result
- Topics for ChatGPT to explain
- Issues/cautions

Do not put long code explanations in the handoff. ChatGPT is responsible for
design discussion, code review, and learning explanations. Do not commit files
from `build/`.
